TEST SUITE CAPABILITIES:
-------------------------
The test suite includes 16 comprehensive tests:

1. Connection Test - Verifies ALICAT is connected and queue manager is valid
2. Get Status - Reads complete device status (flow, temp, valve, gas, flags)
3. Set/Get Setpoint - Tests setpoint control and readback verification
4. Set/Get Gas Type - Tests gas selection (Air, N2, etc.) and verification
5. Tare Function - Tests zero/tare functionality
6. Get Flow Rate - Reads current flow rate measurement
7. Get Temperature - Reads device temperature
8. Get Valve Drive - Reads valve position (0-100%)
9. PID Parameters - Tests reading and setting P and I gains
10. Flow Averaging - Tests setting flow averaging time
11. Reference Temperature - Tests setting reference temperature
12. Setpoint Source - Tests setting setpoint source (analog/digital)
13. Totalizer Functions - Tests totalizer reset and volume accumulation
14. Batch Volume - Tests batch mode volume settings
15. Queued Commands - Verifies command queue functionality
16. Setpoint Ramp - Tests dynamic setpoint changes and flow response

TEST PARAMETERS:
----------------
Defined in tests/alicat_test.h:

- Test Setpoints:
  * Low: 10 sccm
  * Mid: 50 sccm
  * High: 100 sccm

- Test Gas: Air (can be changed in header)

- Tolerances:
  * Flow: ±5 sccm
  * Temperature: ±2°C

- Timing:
  * Short delay: 0.5s
  * Medium delay: 1.0s
  * Long delay: 2.0s
  * Timeout: 5000ms

TESTING PROCEDURE:
------------------
After completing the UI integration:

1. Build the project in LabWindows/CVI 2020
2. Run the Battery Exploder application
3. Ensure ALICAT device is:
   - Physically connected to COM port (default COM7)
   - Configured with correct Modbus address (default 1)
   - Powered on and initialized
4. Click "Test ALICAT" button
5. Monitor the PANEL_MFLOW_STATUS control for test progress
6. Observe log output for detailed test results
7. All 16 tests should pass for proper ALICAT operation

Test Cancellation:
- Click button again during execution to cancel
- Status will show "Test cancelled: X/16 passed"

INTEGRATION PATTERN:
--------------------
This implementation follows the same pattern as BioLogic and DTB tests:

- Callback function checks for running test and handles start/cancel
- Worker thread runs tests in background
- UI updates show progress and results
- System busy flag prevents concurrent operations
- Status string shows one-line summary
- All communication uses queued commands for thread safety

SAFETY CONSIDERATIONS:
----------------------
- Tests will change setpoint values (0-100 sccm range)
- Tests will change gas selection
- Tests will reset totalizer
- Tests will modify PID parameters (restored after test)
- Ensure no critical process is running before testing
- Tests are non-destructive but will temporarily alter settings

QUEUE MANAGER REQUIREMENTS:
----------------------------
The test suite requires:
- ALICAT queue manager initialized (ALICAT_QueueInit)
- Queue manager set as global (ALICAT_SetGlobalQueueManager)
- At least one ALICAT device configured
- Default Modbus address: ALICAT_MODBUS_ADDRESS (from common.h)

TROUBLESHOOTING:
----------------
If tests fail:

1. Connection Test Failure:
   - Check COM port connection
   - Verify Modbus address matches
   - Check baud rate (38400)
   - Ensure device is powered on

2. Communication Failures:
   - Check RS232 cable integrity
   - Verify no other software using COM port
   - Check timeout settings
   - Ensure proper termination

3. Setpoint/Control Failures:
   - Verify gas supply is connected
   - Check for valve restrictions
   - Verify PID parameters are reasonable
   - Check for hardware faults

4. Parameter Mismatch:
   - Some parameters may have limited precision
   - Check tolerance settings in test code
   - Verify device firmware supports feature
