IN EXPERIMENT CODE:

  #include "cdaq_utils.h"

  // Read single channel
  double current_mA;
  if (CDAQ_ReadCurrent(0, &current_mA) == SUCCESS) {
      LogMessage("Sensor current: %.2f mA", current_mA);
  }

  // Read all channels
  double currents[16];
  int num_read;
  if (CDAQ_ReadCurrentArray(currents, &num_read) == SUCCESS) {
      for (int i = 0; i < num_read; i++) {
          LogMessage("Channel %d: %.2f mA", i, currents[i]);
      }
  }

  // Convert to process variable (e.g., 0-100% scale)
  double percent = ((current_mA - 4.0) / 16.0) * 100.0;

================================================================================
STATUS INDICATORS
================================================================================

  OK          - 4.5 to 19.5 mA   (Normal range)
  LOW         - 4.0 to 4.5 mA    (Near minimum)
  HIGH        - 19.5 to 20.0 mA  (Near maximum)
  FAULT       - < 3.5 mA         (Open circuit / disconnected)
  OVER        - > 20.5 mA        (Over-range / wiring fault)

================================================================================
TROUBLESHOOTING
================================================================================

INITIALIZATION ERRORS:

  Error: "Failed to initialize cDAQ current slot"

  Causes:
    • NI 9202 not in slot 1
    • cDAQ chassis not connected
    • NI-DAQmx drivers not installed

  Solutions:
    • Verify hardware installation
    • Check NI MAX for device visibility
    • Reinstall NI-DAQmx drivers if needed

READING ERRORS:

  Error: "Failed to read current"

  Causes:
    • cDAQ not initialized
    • Hardware disconnected
    • Invalid channel number

  Solutions:
    • Check initialization log messages
    • Verify ENABLE_CDAQ is set to 1
    • Use channel 0-15 only

FAULT STATUS READINGS:

  All channels show FAULT (< 3.5 mA)

  Causes:
    • Sensors not powered
    • Open circuit in wiring
    • Shunt resistor not connected

  Solutions:
    • Check 24VDC loop power supply
    • Verify wiring continuity
    • Measure voltage with multimeter

INCORRECT VOLTAGE/CURRENT:

  Voltage doesn't match expected 1-5V range

  Causes:
    • Wrong shunt resistor value
    • Incorrect CDAQ_CURRENT_SHUNT_RESISTOR setting
    • Wiring error

  Solutions:
    • Verify shunt is 250Ω
    • Check cdaq_utils.h configuration
    • Verify wiring diagram

ADDITIONAL NOTES
================================================================================

• The NI 9202 uses VOLTAGE measurement, not direct current measurement
• Shunt resistor converts 4-20mA to 1-5V (V = I × R)
• Software performs automatic I = V / R conversion
• All 16 channels can be used independently
• Readings are on-demand (software-timed), not continuous sampling
• Compatible with standard 4-20mA industrial sensors

• If using different shunt resistor:
  - Update CDAQ_CURRENT_SHUNT_RESISTOR in cdaq_utils.h
  - Update CDAQ_CURRENT_MIN_V and CDAQ_CURRENT_MAX_V accordingly
  - Example: 500Ω → 2-10V range

• Process variable conversion formula:
  PV = ((I_mA - 4) / 16) × (Max - Min) + Min

  Examples:
    0-100%:    PV = ((I_mA - 4) / 16) × 100
    0-500°C:   PV = ((I_mA - 4) / 16) × 500
    50-250PSI: PV = ((I_mA - 4) / 16) × 200 + 50
