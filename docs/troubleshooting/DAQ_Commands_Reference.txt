================================================================================
DAQ COMMAND PROMPT REFERENCE
================================================================================

The DAQ commands provide access to 4-20mA current sensors connected to the
NI 9202 module (slot 1) through the Battery Exploder GUI debug console.

================================================================================
HARDWARE CONFIGURATION
================================================================================

Module:     NI 9202 (slot 1 of cDAQ-9178)
Channels:   16 analog voltage inputs (0-15)
Shunt:      250Ω resistors (converts 4-20mA to 1-5V)
Range:      4mA (1V) to 20mA (5V)

================================================================================
INITIALIZATION
================================================================================

Before using DAQ commands, ensure cDAQ slot 1 is initialized:

1. In BatteryExploder.c main() or initialization function, add:

   #if ENABLE_CDAQ
       if (CDAQ_InitializeCurrentSlot() != SUCCESS) {
           LogError("Failed to initialize cDAQ current sensors");
       }
   #endif

2. In cleanup/shutdown, add:

   #if ENABLE_CDAQ
       CDAQ_CleanupCurrentSlot();
   #endif

================================================================================
TROUBLESHOOTING
================================================================================

┌─ Error: "Failed to read current" ─────────────────────────────────────────┐
│ Possible causes:                                                           │
│   • cDAQ current slot not initialized                                      │
│   • NI 9202 not installed in slot 1                                        │
│   • cDAQ chassis disconnected or powered off                               │
│   • NI-DAQmx driver issue                                                  │
│                                                                            │
│ Solution:                                                                  │
│   • Check CDAQ_InitializeCurrentSlot() is called during startup            │
│   • Verify hardware connections                                            │
│   • Check NI MAX for device visibility                                     │
└────────────────────────────────────────────────────────────────────────────┘

┌─ Readings show FAULT status ──────────────────────────────────────────────┐
│ Possible causes:                                                           │
│   • 4-20mA sensor not powered                                              │
│   • Open circuit in wiring                                                 │
│   • Shunt resistor not connected                                           │
│   • Sensor malfunction                                                     │
│                                                                            │
│ Solution:                                                                  │
│   • Check sensor power supply (typically 24VDC)                            │
│   • Verify wiring continuity                                               │
│   • Measure voltage with multimeter (should be 1-5V)                       │
└────────────────────────────────────────────────────────────────────────────┘

┌─ Voltage seems incorrect ─────────────────────────────────────────────────┐
│ Possible causes:                                                           │
│   • Wrong shunt resistor value                                             │
│   • Shunt resistor not in series with current loop                         │
│   • Incorrect wiring                                                       │
│                                                                            │
│ Solution:                                                                  │
│   • Verify shunt is 250Ω (±1% tolerance)                                   │
│   • Check CDAQ_CURRENT_SHUNT_RESISTOR in cdaq_utils.h matches actual value │
│   • Use DAQV command to verify voltage, calculate: I = V / 250             │
└────────────────────────────────────────────────────────────────────────────┘

================================================================================
PROCESS VARIABLE CONVERSION
================================================================================

If your 4-20mA sensor represents a process variable (temperature, pressure, etc.),
convert the current reading using:

  Process Value = ((I_mA - 4) / 16) × (Max - Min) + Min

Examples:

  • 0-100% scale:
    Percent = ((I_mA - 4) / 16) × 100

  • 0-500°C temperature:
    Temp = ((I_mA - 4) / 16) × 500

  • 50-250 PSI pressure:
    Pressure = ((I_mA - 4) / 16) × 200 + 50

Current Reading Examples:
  • 4.0 mA  → 0% / 0°C / 50 PSI
  • 12.0 mA → 50% / 250°C / 150 PSI
  • 20.0 mA → 100% / 500°C / 250 PSI

================================================================================
INTEGRATION WITH EXPERIMENTS
================================================================================

You can call cDAQ functions directly in your experiment code:

  #include "cdaq_utils.h"

  // Read single channel
  double current_mA;
  if (CDAQ_ReadCurrent(0, &current_mA) == SUCCESS) {
      LogMessage("Sensor current: %.2f mA", current_mA);
  }

  // Read all channels
  double currents[16];
  int num_read;
  if (CDAQ_ReadCurrentArray(currents, &num_read) == SUCCESS) {
      for (int i = 0; i < num_read; i++) {
          LogMessage("Channel %d: %.2f mA", i, currents[i]);
      }
  }
