INTEGRATION PATTERN:
--------------------
This implementation follows the same pattern as the BioLogic test suite:
- Callback function checks for running test and handles start/cancel
- Worker thread runs tests in background
- UI updates show progress and results
- System busy flag prevents concurrent operations
- LED color indicates test outcome (green=pass, red=fail, yellow=cancelled)

NOTES:
------
- The test suite uses the existing DTB queue manager (g_dtbQueueMgr)
- Tests execute using the queued command interface
- Each test runs independently and reports pass/fail status
- Full test log output goes to the logging system
- Status string shows one-line summary
- LED provides visual feedback
